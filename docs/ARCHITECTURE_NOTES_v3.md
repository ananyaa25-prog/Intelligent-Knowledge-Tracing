# Architecture notes v3 (verified from code, Stage 1)

1. Data pipeline: `src/dataset.py` reads `data/raw/skill_builder_data.csv` (ASSISTments 2009 skill-builder), explodes multi-skill rows, drops students with <10 rows, reindexes 123 skills to 1..123, splits students 80/10/10 (seed 42; 2495/311/313), derives per-problem difficulty buckets (0 unknown, 1 easy, 2 medium, 3 hard) from the TRAIN split only, pads to 500 and pickles to `data/processed/windowed_data.pkl` (keys: skill/correct/response_time/attempt/hint/difficulty/problem/window_id seqs + mask).
2. Skill graph: `src/graph_builder.py` -> `data/processed/skill_graph.pkl` (PPMI co-occurrence adjacency 124x124, skill_map raw->internal id).
3. Model: `src/model.py` `GatedKTModel(num_skills, use_graph, use_gate)`; inputs skill+correct+difficulty embeddings, short-term GRU over a 10-step window, long-term GRU, metadata MLP (log RT, attempts, hint), GAT-style graph encoder, vector gate fusing short/long; `forward()` predicts correct[1:], `predict_candidates()` scores (skill, bucket) pairs from the final state.
4. Training/eval entry points: `src/train.py` (3 seeds x {dkt_only, graph_no_gate, full_gated}, 15 epochs, Adam 1e-3, batch 32; best-val checkpoints `data/processed/best_<cond>_seed<s>.pt`), `src/evaluate_test.py` (test AUC from those checkpoints). Served checkpoint `best_full_gated.pt` = seed 42.
5. Predictor interface (serving): `inference_service._predictor(history, [(raw_skill_id, bucket)]) -> [P]` with history items {skill_id|topic, correct, difficulty_bucket, response_time_ms, attempt_count, hint_used}; unknown skills -> 0.5; optional temperature scaling (`calibration.py`).
6. Session engine: `src/serving/adaptive_session.py` (10 ASSISTments topics, warm-up 2, 15 main + 2 probes or core5 = 14+2; topic = lowest P or evidence_blend; level by POLICY staircase|model|random with guardrails).
7. Question bank: `src/serving/question_templates.py` (10 positions x easy/medium/hard parametric templates, answer string compare or |diff|<=0.01); `question_bank.json` is the old fixed bank (legacy flow).
8. Mastery/profile: `src/serving/mastery.py`, `v2_routes.py` (/profile, /class/overview, /feedback); DB `src/serving/db.py` (SQLite `kt_sessions.db`), JSONL log `session_logs.jsonl`.
9. Config flags: `src/serving/policy_config.py` reads env POLICY, TARGET_P, APPLY_CALIBRATION, SESSION_MODE, TOPIC_SELECTION, CORE_TOPICS, T_PROF, T_READY, MIN_ANSWERS, MONOTONE_WARN; defaults = original behaviour; `demo.env` holds gate-selected demo values (staircase, calibration on, core5, evidence_blend).
10. Simulator: `scripts/simulate.py` (150 paired synthetic students, policies staircase/model/random, in-band share and status accuracy) -> `reports/simulation*.md`; gates applied by `scripts/apply_gates.py`.
11. HTTP: FastAPI `src/serving/inference_service.py` (:8000) behind Node/Express proxy `server/src/index.js` (:3000, `/api/*`); front end `server/public/` (app.js, adaptive_ui.js, dashboard*.js); `scripts/_services.py` starts both, `scripts/e2e_http_check.py` checks contracts.
12. Tests: `tests/` (pytest; conftest isolates DB/log into temp copies), `server/tests/*.js` (plain node scripts). Baseline v3: pytest 85 passed / 15 failed (legacy fixed-quiz flow, unchanged since v2), Node 1/4 suites pass (`test_v2_routes.js`; 3 legacy suites fail as documented in v2).
13. Reported v2 numbers (3 seeds, val AUC from retrain.log): dkt_only 0.8915, graph_no_gate 0.8900, full_gated 0.8950.
14. v3 output locations: `models_v3/`, `reports/v3/`, `data/processed_v3/`; new code in `src/baselines/`, `src/questions/`, `src/data/adapters/`; external datasets expected in `data/external/`.
15. Protected (never written by v3): `data/raw/`, `data/processed/*.pt`, `windowed_data.pkl`, `skill_graph.pkl`, `kt_sessions.db`.

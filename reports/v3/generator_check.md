- Complexity (by construction) is strictly ordered easy < medium < hard for 23 of 23 topics.
- The independent surface proxy (digit characters in the text) is strictly ordered for 17 of 23 topics. Where it is not, harder items use fewer but harder numbers (e.g. multiple-choice factorising, exponent rules), so this proxy is weak; it is NOT evidence about how hard students find the items.
- 'Distinct of N' below N means the parameter space for that topic/level is small; the session engine still never repeats an item text within a session (it re-draws, and flags `repeated` if impossible).
- None of this shows that the levels match real student difficulty: that needs logged answers (calibration) and a teacher review of the items (see docs/QUESTION_GENERATOR.md).

## Notes

- Transfer between ASSISTments and these data is not possible with these models: the skill ids differ (no shared skill vocabulary), so every external result comes from a model trained on that dataset.
- A section is labelled "validated on real data" in the app only if a real dataset for that level was loaded and evaluated here; see src/serving/sections.py and docs/DECISIONS.md.
